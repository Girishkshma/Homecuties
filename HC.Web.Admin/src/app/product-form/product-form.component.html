Images

Save the product first - a product's photos are added from its own page. Every photo file is named after the product's id, exactly as the shop's other photos are, so this page opens again with the picture picker as soon as the product is created.

Upload each photo once and tick the sizes to write. The API fits the photograph into each ticked size's box and the product is saved with one row per size, which is what the shop's pages are pictured from. The sizes the storefront draws come ticked already - untick one and no file is written for it. The pixels beside each file name are the file's own rather than its box: a photo wider than it is tall is written wider than it is tall, not cut to the box. Uploading the same photo again replaces it.

Sizes to write
One photograph needs at least one size. Without the promo (P) the shop's cards, cart rows and order rows are pictured from the largest size the photo does have, and a photo written only as a thumbnail is drawn soft in the product page's frame. Tick the two sizes no screen draws only when something else - a feed, a printed sheet - asks for that shape.
